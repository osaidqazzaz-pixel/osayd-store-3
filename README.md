# متجر Osayd — دليل التشغيل قبل النشر

الموقع جاهز من ناحية الكود، بس فيه 3 خدمات خارجية لازم تربطها بحسابك قبل ما ينشتغل صح: **Firebase** (لتخزين البيانات ومزامنتها بين كل الزوار)، **PayPal** (للدفع الإلكتروني)، و**GitHub Pages** (لاستضافة الموقع).

---

## 1) إعداد Firebase (قاعدة البيانات + تسجيل الدخول)

1. روح لـ https://console.firebase.google.com وسجّل دخول بحساب Google، وأنشئ مشروع جديد (مجاني).
2. من القائمة الجانبية: **Build → Firestore Database → Create database**. اختر **Production mode** وأي موقع سيرفر قريب.
3. من القائمة الجانبية: **Build → Authentication → Get started**. فعّل **Email/Password** من تبويب Sign-in method.
4. من **Project settings (⚙️) → عام → إعدادات الموقع (</> Web app)**. سجّل تطبيق ويب جديد، وانسخ كائن `firebaseConfig` اللي رح يظهرلك.
5. افتح ملف `index.html` ودور على كلمة `firebaseConfig` (قريب من بداية الكود)، واستبدل القيم الوهمية بإعداداتك الحقيقية.
6. من تبويب **Firestore Database → Rules**، امسح المحتوى الموجود، والصق محتوى ملف `firestore.rules` المرفق هون، واضغط **Publish**.
7. **مهم جدًا:** أول شي اعمله بعد الرفع هو تسجيل حساب بإيميلك (`osaidqazzaz@gmail.com`) من صفحة "إنشاء حساب" بالموقع نفسه، وبعدين افتح بريدك واضغط رابط "تفعيل البريد" اللي رح توصلك. من دون هالخطوة ما رح تقدر تدير المتجر كمالك.
8. من **Authentication → Settings → Authorized domains**: ضيف نطاق GitHub Pages تبعك (زي `username.github.io`) بعد ما تنشر الموقع بالخطوة 3 تحت.

## 2) إعداد PayPal (لقبول الدفع بـ PayPal وبطاقة الائتمان)

1. سجّل حساب PayPal Business على https://www.paypal.com (لاحظ: PayPal فرض مؤخرًا إجراءات تحقق هوية إضافية على مستخدمي فلسطين — راجع حسابك للتأكد إنه مفعّل بالكامل لاستلام الدفعات قبل الاعتماد عليه).
2. روح لـ https://developer.paypal.com → **Apps & Credentials**، وأنشئ تطبيق جديد (Live، مو Sandbox، وقت ما تكون جاهز للنشر الفعلي).
3. انسخ الـ **Client ID**.
4. افتح `index.html` ودور على `YOUR_PAYPAL_CLIENT_ID` (بأول سطر فيها `<script src="https://www.paypal.com/sdk/js...">`)، واستبدلها بالـ Client ID تبعك.

> إذا ما بدك تفعّل PayPal هلأ، اترك القيمة الوهمية — طرق الدفع التانية (نقدًا، تحويل بنكي، محفظة إلكترونية) رح تشتغل عادي، وبس زر PayPal/البطاقة رح يظهر رسالة "تعذر تحميل بوابة الدفع" لحد ما تحطّ Client ID حقيقي.

## 3) نشر الموقع على GitHub Pages

1. أنشئ مستودع (Repository) جديد على GitHub.
2. ارفع ملف `index.html` (وباقي الملفات إذا حبيت) لجذر المستودع.
3. من إعدادات المستودع: **Settings → Pages**، اختار الفرع `main` والمجلد `/ (root)`، واحفظ.
4. بعد دقيقة أو دقيقتين، رح يصير الموقع متاح على رابط شبيه بـ:
   `https://username.github.io/repo-name/`
5. رجّع لخطوة Firebase Authorized domains (فوق) وضيف هالنطاق.

---

## شو بيصير مباشرة بعد النشر؟

- أي منتج أو طلب أو تعديل بيسويه المالك بيظهر **فورًا** لكل زوار الموقع (مزامنة حية عبر Firestore).
- لون المتجر (من صفحة الإعدادات) بينطبق على كل الزوار مباشرة، والتأثيرات الحركية (التوهج، الحركة عند مرور الماوس) بتضل شغالة بنفس الأسلوب، بس بلون مختلف.
- كل كلمات المرور محمية عبر نظام Firebase Authentication الرسمي (مش مخزّنة على الموقع إطلاقًا).

## نقاط لازم تنتبهلها

- **بدّل معلومات الدفع اليدوي الوهمية:** دور على `STORE_PAYMENT_INFO` جوا الكود وحط رقم الآيبان ورقم محفظتك الإلكترونية الحقيقيين بدل `[PSXX...]` و `[09XXXXXXXX]`.
- **لا تشارك مفتاح PayPal السري (Secret)** مع أي حدا ولا تحطه بالكود — بس الـ Client ID هو اللي ينحط بالموقع، وهو آمن للنشر العلني.
- بما إنو الموقع بالكامل client-side بدون سيرفر خاص فيك، عمليات الدفع الإلكتروني (PayPal) ما فيها تحقق من طرف سيرفر ثاني — وهاد مقبول لمتجر صغير، بس لو المتجر كبر بالمستقبل ينصح بإضافة Cloud Function للتحقق من الدفعات بشكل إضافي.
